CI में लगाएं
# .github/workflows/kasauti.yml — हर PR पर चलेगा
python harness.py --local --base saaras:v3 --cand saaras:v4 --snr 10 --threshold 0.05

# या deployed URL के ख़िलाफ़:
python harness.py --url https://<your-vercel-url> --snr 10

# kasauti_report.json में पूरा JSON लिखता है
क्यों एक ही ऑडियो? — दोनों मॉडल byte-identical noisy audio सुनते हैं (fixed seed), इसलिए delta सिर्फ़ मॉडल का है, input का नहीं।
क्यों LLM जज? — WER कहता है "₹2,450" ≠ "दो हज़ार चार सौ पचास"; जज अर्थ देखता है और गलत OTP, नाम, राशि पकड़ता है।
